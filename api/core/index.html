    AgentFOVCamera ¶

    AgentFOVCamera(config: CameraConfig = None)

    Bases: CameraStrategy

    Shows only the agent's current room.

    The crop is always room_size × room_size tiles (always square). Walls between rooms naturally prevent the agent from seeing into adjacent rooms — no additional fog-of-war mask is needed.
