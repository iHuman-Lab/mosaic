# Contributor Covenant Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of age, body size, disability, ethnicity, gender identity and expression, level of
experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

**Expected behavior:** be respectful and welcoming, give and accept constructive feedback
gracefully, and focus on what is best for the research community.

**Unacceptable behavior:** harassment, insulting or derogatory comments, personal or political
attacks, publishing others' private information, and other conduct reasonably considered
inappropriate in a professional setting.

Maintainers may remove, edit, or reject contributions that violate this Code of Conduct. Instances
of abusive behavior may be reported by opening a confidential report to the maintainers via the
contact listed on the [iHuman-Lab GitHub organization](https://github.com/iHuman-Lab).

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
